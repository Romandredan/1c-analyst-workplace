## Входы

Использованы (папка docs):
- research/vip/01-письмо.md - исходная постановка (директор по развитию розничных продаж);
- research/vip/02-извлечение-требований.md - результат извлечения требований по встрече 1;
- research/vip/03-встреча-2-транскрипт.md - расшифровка встречи 2;
- research/vip/04-ответы-заказчика.md - ответы заказчика;
- research/vip/05-подтверждение-заказчика.md - подтверждение решений владельцем процесса (2026-11-09);
- adr/0001-оплата-отдельный-мерчант-vip.md (proposed), adr/0002-фискализация-реализация-по-факту-оплаты.md (proposed).

Отсутствуют в источниках: расшифровка встречи 1 (факты берутся из извлечения требований), приложение к письму (таблица менеджера с клиентами), итог прожарки решений кроме строки в ADR-0002 (подтверждение бухгалтерии не получено), результаты проверок данных и конфигурации, ответы на Q-E1 и Q-P3.

## Проход 3 не требуется

Экраны форм в этой версии не нужны (решение пользователя). Заглушки S1 и S2 остаются комментариями в package.md без видимых подписей и картинок. Если экраны понадобятся, проход 3 запускается обычным порядком: подписи заглушек восстанавливаются, прототипы строятся по тексту этапов 3 и 4.

## Решения о статусах

Подтверждены владельцем процесса (письмо от 2026-11-09, docs/research/vip/05-подтверждение-заказчика.md, формулировки версии 1): Р-1, Р-2, Р-3, Р-6, Р-7, Р-8.

Остаются «Предложено»: Р-4 (ждёт подтверждения бухгалтерии, вопрос 1) и Р-5 (ждёт решения по сроку ожидания оплаты, вопрос 2). Оба ADR по-прежнему имеют статус proposed: перевод ADR-0001 в accepted решает его владелец.

## Вопросы для разработки
Технические вопросы В-1..В-8 находятся в разделах 8 и 9 package.md (полный профиль). Вопросов к заказчику: 5 (раздел 11).
