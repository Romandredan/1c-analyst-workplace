# Ответы заказчика на вопросы после первой встречи

Источник: вторая встреча (`03-встреча-2-транскрипт.md`) и решения владельца
процесса, сообщённые аналитику после неё. Номера вопросов по отчёту
`02-извлечение-требований.md`.

| Вопрос | Ответ | Кто ответил |
|---|---|---|
| Q-P1. Момент чека | Реализация и чек создаются только по факту оплаты. Причина: VIP-клиент может отказаться от товара в последний момент; если реализация и чек «передача в кредит» уже оформлены, а период закрыт бухгалтерией, разбор требует ручных действий и согласования с бухгалтерией. Товар передаётся клиенту до оплаты без чека | Владелец процесса; подтверждение бухгалтерии запрошено |
| Q-P2. Неоплата через N дней | Автоматических напоминаний нет: об оплате договариваются лично, через помощников клиента | Владелец процесса |
| Q-P4. Что отдельное | Отдельный мерчант для VIP-продаж (уведомления об оплате приходят в 1С) и отдельная касса; отдельного склада для товара на примерке нет, товар держится резервом в заказе | Владелец процесса |
| Возвраты | Возврат после покупки повторяет схему продажи: вместо заказа заявка на возврат. Возвраты единичны | Владелец процесса |
| Услуги | В заказе только товар; платной доставки и платной примерки нет | Владелец процесса |
| Сертификаты | Вне периметра этого этапа: оплата подарочными сертификатами в VIP-процесс сейчас не включается | Владелец процесса |
| Бонусы | Бонусы программы лояльности рассматриваются как скидка на покупку; отдельного способа оплаты бонусами нет | Владелец процесса |
| Доступ менеджера к 1С на выезде | Пока нет; итоги примерки менеджер вносит после возвращения. Планшеты в планах, процесс от этого не меняется | Владелец процесса |
| Q-E1. Срок жизни ссылки | Не получен | |
| Q-P3. Тариф кассы за год | Не получен | |
