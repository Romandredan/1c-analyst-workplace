## ADDED Requirements

### Requirement: VIP-продажи используют отдельную кассу
Система SHALL проводить все кассовые документы по заказам на примерку через отдельную кассу, выделенную для VIP-продаж. Система SHALL NOT пробивать чеки по этим заказам на общей кассе других потоков продаж.

#### Scenario: Чек по VIP-заказу уходит на отдельную кассу
- **WHEN** система формирует кассовый документ по заказу на примерку
- **THEN** документ отправляется на отдельную кассу VIP
- **AND** общая касса других потоков продаж не используется

#### Scenario: Кассовый документ по заказу не из VIP-потока
- **WHEN** система формирует кассовый документ по заказу, не относящемуся к выездной примерке
- **THEN** документ уходит на кассу своего потока
- **AND** отдельная касса VIP не используется
